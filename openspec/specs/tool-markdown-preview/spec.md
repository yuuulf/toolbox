# tool-markdown-preview Specification

## Purpose
Markdown を入力と同時にプレビューし、GFM と Mermaid の図もブラウザ内で表示するツール。入力内容は「保存」を押したときだけ localStorage に1件保存する。

## Requirements

### Requirement: 入力と同時にプレビューする
ツールは Markdown の入力欄とプレビューを持ち、入力欄の内容が変わるたびに、ボタン操作なしでプレビューを更新しなければならない（SHALL）。

#### Scenario: 見出しと強調
- **WHEN** ユーザーが `# タイトル\n\n**太字**` を入力する
- **THEN** プレビューに見出し「タイトル」と、太字の「太字」が表示される

#### Scenario: 入力が空
- **WHEN** 入力欄が空である
- **THEN** プレビューに「Markdown を入力するとここに表示されます。」が表示される

### Requirement: GFM に対応する
ツールは GitHub Flavored Markdown の表・タスクリスト・取り消し線・URL の自動リンクを表示しなければならない（SHALL）。タスクリストのチェックボックスはプレビュー上で変更できない表示にする。

#### Scenario: 表とタスクリスト
- **WHEN** ユーザーが `| a | b |\n|---|---|\n| 1 | 2 |\n\n- [x] 済み\n- [ ] 未完了` を入力する
- **THEN** 2列の表と、チェック済み・未チェックのチェックボックス付きの項目が表示され、チェックボックスは操作できない

### Requirement: Mermaid の図を描く
言語が `mermaid` のコードブロックを、ツールは Mermaid の図として描かなければならない（SHALL）。図の配色は OS のライト/ダーク設定に合わせる。図の描画に必要な処理は、`mermaid` のコードブロックがあるときだけ読み込む。

#### Scenario: フローチャート
- **WHEN** ユーザーが ` ```mermaid\ngraph TD\n  A[開始] --> B[終了]\n``` ` を入力する
- **THEN** プレビューに「開始」から「終了」へ矢印が伸びた図が表示される

#### Scenario: ダークモード
- **WHEN** OS がダークモードのブラウザで図を表示する
- **THEN** 図は暗い背景に合う配色で描かれる

### Requirement: 図の構文エラーを表示する
Mermaid の構文に誤りがあるとき、ツールはその図の位置に「図を描けませんでした。」とエラーの内容を表示し、元のコードも表示しなければならない（SHALL）。ほかの図や Markdown のプレビューは表示し続けなければならない。

#### Scenario: 誤った図とほかの内容
- **WHEN** ユーザーが `# 見出し` と、` ```mermaid\ngraph TD\n  A -->\n``` ` を入力する
- **THEN** 見出しは表示され、図の位置に「図を描けませんでした。」とエラーの内容、元のコードが表示される

### Requirement: 表示を切り替える
ツールは「並べて表示」「入力のみ」「プレビューのみ」の3つの表示を切り替えられなければならない（SHALL）。初期表示は「並べて表示」で、入力欄を左、プレビューを右に置く。「入力のみ」「プレビューのみ」では、それぞれを画面幅いっぱいに表示する。切り替えはキーボードでも操作でき、選んでいる表示が分からなければならない。表示の選択は保存しない。画面幅が 1024px 未満の「並べて表示」では、入力欄とプレビューを縦に並べる。

#### Scenario: プレビューのみ
- **WHEN** ユーザーが「プレビューのみ」を選ぶ
- **THEN** 入力欄は表示されず、プレビューが画面幅いっぱいに表示される

#### Scenario: 入力のみから戻る
- **WHEN** 「入力のみ」で入力した後に「並べて表示」を選ぶ
- **THEN** 入力した内容は残ったまま、入力欄とプレビューが左右に並ぶ

### Requirement: ボタンを押したときだけ保存する
ツールは「保存」ボタンを押したときだけ、入力欄の内容を localStorage に保存しなければならない（SHALL）。保存できるのは1件だけで、保存すると前の内容を置き換える。入力しただけでは保存してはならない。保存の結果は、ボタンのアイコンを約2秒だけ切り替えて示す（成功は ✓、失敗は ×）。成功と失敗は色だけでなくアイコンの形で区別でき、結果の文言（「保存しました」「保存できませんでした」）は画面に表示せず、スクリーンリーダーで読み上げられるようにする。

#### Scenario: 保存して再読み込み
- **WHEN** ユーザーが Markdown を入力して「保存」を押し、ページを再読み込みする
- **THEN** 保存ボタンのアイコンが一時的に ✓ に変わり、「保存しました」が読み上げられ、再読み込み後の入力欄に保存した内容が入っている

#### Scenario: 元の表示に戻る
- **WHEN** 保存の結果のアイコンが表示されてから約2秒が経過する
- **THEN** ボタンは元の保存のアイコンに戻る

#### Scenario: 保存せずに再読み込み
- **WHEN** 保存した後に入力欄を書き換え、「保存」を押さずに再読み込みする
- **THEN** 入力欄には最後に保存した内容が入っている

#### Scenario: localStorage が使えない
- **WHEN** localStorage への書き込みが例外を投げる環境で「保存」を押す
- **THEN** 保存ボタンのアイコンが一時的に × に変わり、「保存できませんでした」が読み上げられ、入力とプレビューはそのまま使える

### Requirement: HTML と画像を読み込まない
ツールは Markdown の中の HTML を解釈せず、文字のまま表示しなければならない（SHALL）。画像の記法は画像を読み込まず、代替テキストと URL を表示しなければならない。`javascript:` など安全でない URL のリンクは無効にしなければならない。リンクは新しいタブで開く。

#### Scenario: HTML のタグ
- **WHEN** ユーザーが `<b>太字?</b>` を入力する
- **THEN** プレビューには `<b>太字?</b>` が文字のまま表示され、太字にはならない

#### Scenario: 画像の記法
- **WHEN** ユーザーが `![ロゴ](https://example.com/logo.png)` を入力する
- **THEN** 画像は読み込まれず（`example.com` への通信が発生しない）、「ロゴ」と URL が表示される

#### Scenario: 危険なリンク
- **WHEN** ユーザーが `[押す](javascript:alert(1))` を入力する
- **THEN** 「押す」は表示されるが、クリックしてもスクリプトは実行されない
