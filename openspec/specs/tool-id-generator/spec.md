# tool-id-generator Specification

## Purpose

暗号論的に安全な乱数を用いて、UUID v4 とランダムパスワードをブラウザ内で生成するツール。保存するのはパスワード生成オプションのみで、保存先は localStorage とする。

## Requirements

### Requirement: UUID v4 を生成する
ツールは RFC 9562 形式の UUID バージョン4 を、指定された個数（1〜100、既定 1）だけ生成して1行に1つずつ表示しなければならない（SHALL）。

#### Scenario: 1件生成
- **WHEN** ユーザーが個数 1 で UUID 生成を実行する
- **THEN** `xxxxxxxx-xxxx-4xxx-[89ab]xxx-xxxxxxxxxxxx` 形式（小文字16進）の UUID が1つ表示される

#### Scenario: 複数生成
- **WHEN** ユーザーが個数 5 で UUID 生成を実行する
- **THEN** 互いに異なる UUID が5行表示される

#### Scenario: 範囲外の個数
- **WHEN** ユーザーが個数に 0 または 101 を指定する
- **THEN** 生成は行われず、1〜100 の範囲で指定するよう表示される

### Requirement: ランダムパスワードを生成する
ツールは指定された長さ（4〜128、既定 16）と文字種（英大文字・英小文字・数字・記号）に従ってパスワードを生成しなければならない（SHALL）。選択された各文字種から少なくとも1文字を含めなければならない。

#### Scenario: 既定設定で生成
- **WHEN** ユーザーが既定設定のままパスワード生成を実行する
- **THEN** 英大文字・英小文字・数字・記号をそれぞれ1文字以上含む16文字のパスワードが表示される

#### Scenario: 数字のみ
- **WHEN** ユーザーが文字種を「数字」のみにして長さ 8 で生成する
- **THEN** 数字のみからなる8文字のパスワードが表示される

#### Scenario: 文字種が未選択
- **WHEN** ユーザーがすべての文字種のチェックを外す
- **THEN** 生成は行えず、文字種を1つ以上選ぶよう表示される

### Requirement: 安全な乱数を使用する
ツールは UUID とパスワードの生成に、ブラウザの暗号論的に安全な乱数源を使用しなければならない（MUST）。予測可能な疑似乱数を使用してはならない。文字の選択に偏りが生じてはならない。

#### Scenario: 乱数源
- **WHEN** UUID またはパスワードを生成する
- **THEN** 値は Web Crypto API の乱数から導出される

### Requirement: 生成結果をコピーする
ツールは生成したUUID（複数の場合は改行区切りの全件）とパスワードを、それぞれワンクリックでクリップボードにコピーできなければならない（SHALL）。2つのコピーボタンは、アクセシブルな名前（「UUID をコピー」「パスワードをコピー」）で区別できなければならない。コピーボタンとその結果の示し方は、toolbox 共通のコピー操作の要件（アイコンのみのボタン、アイコンの切り替えと読み上げ）に従わなければならない。

#### Scenario: パスワードのコピー
- **WHEN** ユーザーがパスワードのコピーボタン（アクセシブルな名前「パスワードをコピー」）を押す
- **THEN** パスワードがクリップボードに書き込まれ、ボタンのアイコンが一時的にチェックに変わり、「コピーしました」が読み上げられる

#### Scenario: UUID のコピー
- **WHEN** ユーザーが UUID を複数生成し、UUID のコピーボタン（アクセシブルな名前「UUID をコピー」）を押す
- **THEN** 生成した UUID の全件が改行区切りでクリップボードに書き込まれる

### Requirement: パスワード生成オプションを localStorage に保存する
ツールはパスワードの長さと文字種の選択を localStorage に保存し、次回表示時に復元しなければならない（SHALL）。保存値が不正または読み込めない場合は既定値を使用しなければならない。

#### Scenario: 設定の復元
- **WHEN** ユーザーが長さを 24 にし、記号のチェックを外してからページを再読み込みする
- **THEN** 長さ 24・記号なしの設定が復元される

#### Scenario: 不正な保存値
- **WHEN** localStorage の保存値が壊れている（JSONとして読めない、範囲外の長さなど）
- **THEN** 既定値（長さ 16、全文字種選択）で表示される

### Requirement: 生成した値は保存しない
ツールは生成した UUID とパスワードそのものを localStorage を含むいかなる場所にも保存してはならない（MUST NOT）。

#### Scenario: 再読み込み後の生成結果
- **WHEN** ユーザーがパスワードを生成した後にページを再読み込みする
- **THEN** 以前に生成したパスワードは表示されず、localStorage にも含まれない
