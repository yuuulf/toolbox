# Spec Delta

## ADDED Requirements

### Requirement: 値を変えられない結果は編集できない表示欄で表示する
システムは、ユーザーが値を変えられないツールの結果（JSON整形/検証の出力、UUID/パスワード生成の生成結果と生成したパスワード、Markdownプレビュー）を、テキスト入力欄ではなく、編集できない表示欄で表示しなければならない（SHALL）。表示欄は、クリックしても文字カーソルやサイズ変更のつまみを出してはならない。表示欄は見出しと同じ名前でスクリーンリーダーに読み上げられ、キーボードでフォーカスしてスクロールでき、マウスで文字の一部を選んでコピーできなければならない。値の改行・インデント・空白はそのまま表示する。

#### Scenario: 入力欄として扱われない
- **WHEN** JSON整形/検証で JSON を整形する、または UUID とパスワードを生成する
- **THEN** 「出力」「生成結果」「生成したパスワード」はテキスト入力欄ではなく、それぞれの名前の付いた表示領域として扱われ、クリックしても文字カーソルとサイズ変更のつまみが出ない

#### Scenario: 整形結果の見た目を保つ
- **WHEN** JSON をインデント「タブ」で整形する
- **THEN** 出力の表示欄に、改行とタブのインデントがそのまま表示される

#### Scenario: キーボードでスクロールする
- **WHEN** 表示欄に収まらない長さの結果（数百行の JSON、100 件の UUID、128 文字のパスワード）を表示し、キーボードで表示欄にフォーカスを移す
- **THEN** 矢印キーで表示欄の中を縦または横にスクロールでき、ページ全体は伸びない

#### Scenario: 一部を選んでコピーする
- **WHEN** 表示欄の文字の一部をマウスで選び、ブラウザのコピー操作を行う
- **THEN** 選んだ部分の文字がコピーされる

#### Scenario: 結果が空のとき
- **WHEN** JSON の入力が空またはエラーで出力がない、またはパスワードがまだ生成されていない
- **THEN** 表示欄は空のまま、少なくとも1行分の高さの枠として表示される
