# Spec Delta

## MODIFIED Requirements

### Requirement: 共通ヘッダーとツール間ナビゲーション
システムはすべてのページに、トップページへ戻るアプリ名のリンクと、登録済みツールへのナビゲーションを表示しなければならない（SHALL）。画面幅が 1024px 以上のときは、これらを画面の左のサイドバーに縦に並べ、常に表示する。1024px 未満のときは、画面の上部のバーにアプリ名のリンクとメニューボタンを置き、ナビゲーションはメニューボタンで開くメニューの中に表示する。現在表示中のツールはナビゲーション上で区別できなければならない。アプリ名の左には toolbox のアイコンを表示し、OS のライト/ダーク設定に合わせてファビコンと同じ2種類を切り替えなければならない。アイコンは飾りとして扱い、リンクの読み上げ名はアプリ名のままでなければならない。

#### Scenario: ツールページからトップへ戻る
- **WHEN** ユーザーがツールページでアプリ名「toolbox」をクリックする
- **THEN** `/` に遷移する

#### Scenario: 現在のツールが強調される
- **WHEN** ユーザーが `/tools/id-generator` を表示している
- **THEN** ナビゲーション上の「UUID/パスワード生成」が他の項目と視覚的に区別される

#### Scenario: アプリ名の隣のアイコン
- **WHEN** ユーザーがライトモードまたはダークモードでいずれかのページを開く
- **THEN** 「toolbox」の左に、そのモードのファビコンと同じアイコンが表示され、アイコンをクリックしてもトップページへ遷移する。スクリーンリーダーではリンクが「toolbox」と読み上げられ、アイコンは読み上げられない

#### Scenario: 広い画面ではサイドバー
- **WHEN** 画面幅 1470px でいずれかのページを開く
- **THEN** 画面の左にアプリ名とすべてのツールへのリンクが縦に並んで表示され、ページの上部にヘッダーやツール一覧の帯は表示されない。ツールが7つあってもリンクは1列に並ぶ

#### Scenario: 狭い画面ではメニュー
- **WHEN** 画面幅 360px でいずれかのページを開き、上部のバーのメニューボタンを押す
- **THEN** ページの上にすべてのツールへのリンクが重ねて表示される。メニューを開く前は、ツールへのリンクは表示されていない

#### Scenario: メニューを閉じる
- **WHEN** 狭い画面でメニューを開いた後、Esc キーを押す、閉じるボタンを押す、またはツールのリンクを選ぶ
- **THEN** メニューが閉じる。ツールのリンクを選んだときは、そのツールのページに遷移する

#### Scenario: メニューをキーボードで使う
- **WHEN** 狭い画面でキーボードだけを使い、メニューボタンを Enter キーで押す
- **THEN** メニューが開いてフォーカスがメニューの中に移り、Tab キーでツールのリンクを順に移動できる。メニューを閉じるとフォーカスはメニューボタンに戻る。メニューボタンは開いているかどうかをスクリーンリーダーに伝える
