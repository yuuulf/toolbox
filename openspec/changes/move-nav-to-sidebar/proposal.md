# Proposal

## Why

ツールが7つになり、幅 1470px でもヘッダー下のツール一覧が2行に折り返すようになった。ヘッダーとツール一覧で画面の上部を約 140px 使っており、1470×800 に収めるために各ツールの入力欄や結果欄を小さくせざるを得ない（Markdownプレビューでは欄が狭いという指摘があった）。ツールが増えても縦に並べて伸ばせるサイドバーに移し、空いた高さを各ツールで使う。

## What Changes

- **幅 1024px 以上: 左にサイドバーを置く**
  - アプリ名「toolbox」とアイコン（トップへのリンク）と、ツール一覧のナビゲーションを縦に並べる
  - 常に表示する（折りたたまない）。幅は約 224px
  - ページの上部のヘッダーとツール一覧の帯はなくす
  - メインの領域はサイドバーの右に置き、今までどおり最大幅 1024px で中央に寄せる
- **幅 1024px 未満: 上部に細いバーとメニューボタンを置く**
  - バーにはアプリ名とアイコン（トップへのリンク）と、メニューボタン（☰）を置く
  - メニューボタンを押すと、ツール一覧を画面の上に重ねて表示する（ドロワー）。Esc キー、閉じるボタン、ツールの選択で閉じる
- **空いた高さを使う**: 1470×800 で高さが制限されている各ツールの欄を広げる
  - JSON整形/検証: 入力欄・出力欄
  - 文字数カウント: 入力欄
  - UUID/パスワード生成: UUID の生成結果の欄（行数の上限）
  - テキスト差分比較: 入力欄・比較結果の欄
  - チェックリスト: 各リストの一覧
  - Markdownプレビュー: 入力欄・プレビュー
  - カラー変換/コントラストは中でスクロールする欄がないので変えない
- 現在表示中のツールの強調、アイコンのライト/ダークの切り替え、アイコンを読み上げない扱いは今までどおり

## Capabilities

### New Capabilities

なし

### Modified Capabilities

- `toolbox-shell`: 「共通ヘッダーとツール間ナビゲーション」を、幅 1024px 以上のサイドバーと、1024px 未満の上部のバーとメニュー（ドロワー）に変える

## データ保存

すべてのツールで変更なし（画面の配置の変更だけで、保存する内容は変わらない。サイドバーやメニューの状態も保存しない）。

## Out of scope

- サイドバーの折りたたみ（幅の広い画面でサイドバーを隠す機能）
- ツール一覧の検索・並べ替え・グループ分け
- メインの領域の最大幅（1024px）の変更
- カラー変換/コントラストの配置の変更
- 1024px 未満の画面での各ツールの欄の大きさの変更

## Impact

- `app/layout.tsx`（全体の配置）
- `components/header.tsx`・`components/tool-nav.tsx` の置き換え（サイドバー、上部のバーとメニュー、アプリ名のリンク）と、そのテスト
- `components/tools/` の各ツールの欄の高さ（json-formatter・char-counter・id-generator・text-diff・checklist・markdown-preview）
- AGENTS.md の構成図
- 依存パッケージの追加はなし（メニューは HTML の `<dialog>` で作る）
