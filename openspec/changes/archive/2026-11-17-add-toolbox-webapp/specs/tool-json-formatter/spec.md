# Spec Delta

## Purpose

入力されたJSON文字列をブラウザ内で検証し、読みやすく整形または圧縮して出力するツール。データは保存しない。

## ADDED Requirements

### Requirement: JSONを整形する
ツールは有効なJSONを、選択されたインデント（2スペース・4スペース・タブ）で整形して出力しなければならない（SHALL）。既定のインデントは2スペースとする。

#### Scenario: 2スペースで整形
- **WHEN** ユーザーが `{"a":1,"b":[true,null]}` を入力し、インデント「2スペース」で整形を実行する
- **THEN** 出力欄に2スペースでインデントされた複数行のJSONが表示される

#### Scenario: タブで整形
- **WHEN** ユーザーがインデント「タブ」を選んで整形を実行する
- **THEN** 出力の各階層がタブ文字でインデントされる

### Requirement: JSONを圧縮する
ツールは有効なJSONを、不要な空白・改行を除いた1行の文字列として出力できなければならない（SHALL）。

#### Scenario: 圧縮
- **WHEN** ユーザーが改行やインデントを含むJSONを入力し、圧縮を実行する
- **THEN** 出力欄に空白・改行を含まない1行のJSONが表示される

### Requirement: 構文エラーを表示する
入力が有効なJSONでない場合、ツールは出力欄を空にし、エラーメッセージを表示しなければならない（SHALL）。位置情報が取得できる場合は行と列をメッセージに含めなければならない。

#### Scenario: 不正なJSON
- **WHEN** ユーザーが `{"a":1,}` を入力して整形を実行する
- **THEN** エラーメッセージが表示され、成功時の出力は表示されない

#### Scenario: 空入力
- **WHEN** 入力欄が空（または空白のみ）の状態で整形を実行する
- **THEN** 入力が空であることを示すメッセージが表示され、エラー扱いの強調表示はされない

### Requirement: 出力をコピーする
ツールは出力結果をワンクリックでクリップボードにコピーできなければならない（SHALL）。コピー成功時はその旨を一時的に表示しなければならない。

#### Scenario: コピー成功
- **WHEN** 出力がある状態でユーザーがコピーボタンを押す
- **THEN** 出力文字列がクリップボードに書き込まれ、「コピーしました」と一時的に表示される

### Requirement: データを保存しない
ツールは入力・出力・設定を localStorage を含むいかなる場所にも保存してはならない（MUST NOT）。

#### Scenario: 再読み込み
- **WHEN** ユーザーがJSONを入力した後にページを再読み込みする
- **THEN** 入力欄と出力欄は空で表示される
