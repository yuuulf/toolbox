# Design

## Context

- お気に入りの各色は `<li>` の中に「色見本 + HEX のボタン（押すと変換欄に読み込む）」と、境界線で区切った削除ボタン（`IconButton` の `variant="subtle"`、`p-1`・枠なし）を並べている（`components/tools/color-tool/favorite-colors.tsx`）
- `CopyButton`（`components/copy-button.tsx`）は枠あり・`p-2` の見た目だけを持つ。結果はアイコンの切り替え（チェック／×）と `aria-live` の読み上げで伝え、約2秒で戻る
- AGENTS.md は「コピーは必ず `CopyButton` を使う」「追加・削除は `IconButton`」と決めている

## Goals / Non-Goals

**Goals:**

- コピーの動き（書き込み・結果の伝え方・空のとき押せない）は `CopyButton` のものをそのまま使い、お気に入り用に作り直さない
- 一覧の1項目の見た目を、色見本のボタンとコピーボタンが1つのまとまりに見える大きさに保つ

**Non-Goals:**

- `CopyButton` と `IconButton` の統合

## Decisions

### D1. `CopyButton` に `variant` を追加する

`variant?: 'default' | 'subtle'` を追加する。`default` は今の枠あり・`p-2`（既存の呼び出しは変更不要）。`subtle` は `IconButton` の subtle と同じ `rounded p-1 text-zinc-500 hover:bg-zinc-100 hover:text-zinc-900`（ダークも同じ対応）で、枠を付けない。成功・失敗の色（緑・赤）は `subtle` でも付ける。通常時の文字色 `text-zinc-500` とホバー時の `hover:text-zinc-900` は通常時だけ付け、結果を表示している間は付けない（押した直後はポインタが乗ったままなので、ホバーの文字色が付いていると結果の緑・赤が上書きされるため）。

- 代替: お気に入りでは既定の枠ありの `CopyButton` をそのまま置く → 枠と `p-2` で項目の高さが増え、項目の中に枠が二重に見える
- 代替: `IconButton` に `CopyIcon` を渡してコピー処理を書く → コピーの結果の伝え方を二重に実装することになり、AGENTS.md の「コピーは必ず `CopyButton`」にも反する

### D2. 項目の並びは「色見本のボタン | コピー」。一覧の削除ボタンはなくす

`<li>` の右側の境界線で区切った枠の中に、コピーボタンだけを置く。削除ボタン（`IconButton` + `TrashIcon`）と `FavoriteColors` の `onRemove` はなくし、`color-tool.tsx` の `onRemove` の受け渡しも消す。

- 一覧の削除をなくすのは、コピーと削除が隣り合うと押し間違えやすく、削除はコピーより使う頻度が低いため（ユーザーとの相談で決めた）。外すときは、一覧の色を選んで変換欄に読み込み、押された状態の星のボタンを押す。この流れは既存の要件「お気に入りに登録・解除する」でできるので、新しい処理は要らない
- `lib/tools/color-favorites.ts` の `removeFavorite` は `toggleFavorite` から使われているので残す
- 代替: 削除ボタンを残し、確認のダイアログを出す → 操作が増え、押し間違えやすさ自体は変わらない
- コピーボタンの名前は `` `${hex} をコピー` ``
- HEX は保存されている小文字の `#rrggbb` をそのまま渡す（変換欄の HEX のコピーと同じ形式）

### D3. テスト

- `copy-button.test.tsx`: `variant="subtle"` のとき枠のクラス（`border`）を持たず、コピーと結果のアイコン切り替えが既定と同じに動く
- `favorite-colors.test.tsx`: 「#336699 をコピー」を押すとクリップボードに `#336699` が入り、「コピーしました」が読み上げられ、`onSelect` が呼ばれない。Tab で移動して Enter でコピーできる。既存の「キーボードだけで選択と削除ができる」「削除ボタンを押すと onRemove にその HEX が渡る」は、削除ボタンがなくなるので、選択とコピーのキーボード操作のテストと、削除のボタンがないことのテストに置き換える
- `color-tool.test.tsx`: お気に入りに登録した色をコピーしても、変換の入力欄が変わらないことを確かめる（コンポーネントをまたぐふるまいのため）。既存の「一覧から削除できる」は、一覧の色を選んで星のボタンを押すと一覧から消え、localStorage からも消えるテストに置き換える

## Risks / Trade-offs

- [一覧から外すのに2回の操作（選ぶ → 星）が要る] → 外す頻度はコピーより低いので許容する（ユーザーの判断）
- [項目の横幅が広がり、狭い画面で1行に並ぶ数が減る] → `flex-wrap` で折り返すので、はみ出しはしない。幅 390px のスクリーンショットで確かめる
- [`subtle` の状態の色の付け方を間違えると、成功時に緑にならない] → テストで成功時のアイコン（チェック）を確かめ、色はスクリーンショットで確かめる
