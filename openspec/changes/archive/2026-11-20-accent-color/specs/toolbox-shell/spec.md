# Spec Delta

## ADDED Requirements

### Requirement: アクセント色にティールを使う
システムは、ツールの中のリンクの文字色、チェックボックスのチェック時の色、キーボード操作やクリックでフォーカスした要素のフォーカスリングの色に、#009688 を基準とするティールのアクセント色を使わなければならない（SHALL）。リンクの文字は、背景に対して WCAG AA のコントラスト比 4.5:1 以上でなければならない。チェックボックスのチェック時の色とフォーカスリングは、背景に対して 3:1 以上でなければならない。操作できない（disabled の）チェックボックスはアクセント色にせず、ブラウザ既定の表示のままにする。表示は OS のライト/ダークの設定に従い、ダークでは暗い背景で読める明るいティールを使う。塗りつぶしのボタン、ナビの現在地、成功・失敗の表示の色はアクセント色にしない。

#### Scenario: ライトモードのリンク
- **WHEN** OS がライトモードで、Markdownプレビューにリンクを含む Markdown を表示する
- **THEN** リンクは濃いティール（#00796b）の下線つきの文字で表示され、白背景とのコントラスト比が 4.5:1 以上である

#### Scenario: ダークモードのリンク
- **WHEN** OS がダークモードで、Markdownプレビューにリンクを含む Markdown を表示する
- **THEN** リンクは明るいティール（#4db6ac）の下線つきの文字で表示され、暗い背景とのコントラスト比が 4.5:1 以上である

#### Scenario: チェックボックスの色
- **WHEN** チェックリストの項目、UUID/パスワード生成の文字種のチェックボックスがチェックされた状態で表示される
- **THEN** チェックボックスはライトモードでは #009688、ダークモードでは #4db6ac で塗られ、ブラウザ既定の青では表示されない

#### Scenario: 操作できないチェックボックス
- **WHEN** Markdownプレビューのタスクリストのように、操作できない（disabled の）チェックボックスがチェックされた状態で表示される
- **THEN** チェックボックスはアクセント色ではなく、ブラウザ既定の操作できない表示（灰色）のままである

#### Scenario: フォーカスリングの色
- **WHEN** 入力欄にフォーカスする、またはキーボードでボタンやリンクにフォーカスを移す
- **THEN** フォーカスリングはライトモードでは #009688、ダークモードでは #4db6ac で表示され、ブラウザ既定の青では表示されない

#### Scenario: アクセント色にしない部分
- **WHEN** 主ボタン（「整形」「生成」など）、追加ボタン、ナビの現在のツール、コピーの成功・失敗のアイコンを表示する
- **THEN** これらはアクセント色ではなく、これまでどおりの色で表示される
