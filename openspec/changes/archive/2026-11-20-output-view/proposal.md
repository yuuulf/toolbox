# Proposal

## Why

JSON整形/検証の出力と、UUID/パスワード生成の結果は、値を変えられないのに `readOnly` のテキスト欄（textarea / input）で表示している。そのため、クリックすると文字カーソルが出る、右下にサイズ変更のつまみが出るなど、入力欄のように編集できそうに見える。Markdownプレビューの表示欄と同じ「編集できない表示欄」にそろえ、入力欄と見分けられるようにする。

## What Changes

- 次の3つの結果の欄を、テキスト欄から、Markdownプレビューと同じ形式の表示欄（フォーカスしてキーボードでスクロールできる領域）に変える
  - JSON整形/検証の「出力」
  - UUID/パスワード生成の「生成結果」（UUID）
  - UUID/パスワード生成の「生成したパスワード」
- 表示欄では文字カーソルとサイズ変更のつまみを出さない。マウスで一部を選んでコピーすること、キーボードでのスクロール、スクリーンリーダーでの読み上げはこれまでどおりできる
- 欄の名前（「出力」「生成結果」「生成したパスワード」）、コピーボタン、欄の高さ・スクロールのふるまい（1470×800 で縦スクロールなし、UUID は件数に合わせて伸びる）は変えない
- 3か所で使うため、表示欄を共通コンポーネントにする

### Out of scope

- Markdownプレビューの表示欄そのもの（今の形式が基準）
- 値を編集できる欄（JSON の入力、カラー変換の各形式の入力など）
- テキスト差分比較の比較結果（すでに表示専用の領域）
- 出力の内容・コピーの動作・エラー表示の変更

### データ保存

- JSON整形/検証: 保存なし（変更なし）
- UUID/パスワード生成: localStorage（パスワード生成オプションのみ。変更なし）

## Capabilities

### New Capabilities

なし

### Modified Capabilities

- `toolbox-shell`: ツールの結果（値を変えられない出力）を、入力欄と見分けられる編集できない表示欄で表示する要件を追加する

## Impact

- `components/output-view.tsx`（新規、+テスト）: 共通の表示欄
- `components/tools/json-formatter.tsx`（+テスト）: 出力欄を置き換える
- `components/tools/id-generator.tsx`（+テスト）: 生成結果とパスワードの欄を置き換える
- AGENTS.md: ディレクトリ構成と UI の統一に、結果の表示欄の約束を追記する
- 依存パッケージの追加なし。README の更新は不要（ツール・データの扱い・手順は変わらない）
