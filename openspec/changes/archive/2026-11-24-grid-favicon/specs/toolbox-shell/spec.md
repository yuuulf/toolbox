# Spec Delta

## MODIFIED Requirements

### Requirement: toolbox のファビコンを表示する
システムはすべてのページで、toolbox のアイコン（4枚のカードを2×2に並べたマーク）をファビコンとして示さなければならない（SHALL）。アイコンの背景は透明でなければならない。OS がライトモードのときは濃いグレーのカードのアイコンを、ダークモードのときは白のカードのアイコンを示さなければならない。

#### Scenario: ライトモードでページを開く
- **WHEN** OS がライトモードのブラウザで、トップページまたはいずれかのツールページを開く
- **THEN** タブに、2×2に並んだ濃いグレーのカード3枚と緑のカード1枚（右下）のアイコンが透明な背景で表示される

#### Scenario: ダークモードでページを開く
- **WHEN** OS がダークモードのブラウザで、トップページまたはいずれかのツールページを開く
- **THEN** タブに、2×2に並んだ白のカード3枚と緑のカード1枚（右下）のアイコンが透明な背景で表示される

#### Scenario: 公開版でアイコンを読み込む
- **WHEN** 公開版（`https://yuuulf.github.io/toolbox/`）のページを開く
- **THEN** ファビコンの画像は `/toolbox` の下から読み込まれ、404 にならない。Next.js の既定のロゴは表示されない
