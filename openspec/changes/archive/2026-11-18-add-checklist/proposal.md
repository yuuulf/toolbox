# Proposal

## Why

毎月・毎週・毎日くり返す作業（月末の請求処理、週次の振り返り、毎日の確認など）を、紙やメモで毎回書き直さずにチェックしたい。また、その場限りのやることリストも同じ場所で扱いたい。ブラウザ内で完結し、項目とチェックの状態を localStorage に保存するチェックリストツールを toolbox に加える。

## What Changes

新しいツール「チェックリスト」（`/tools/checklist`）を追加する。リストは次の4つ。

- **繰り返しのチェックリスト（月次・週次・日次）**
  - 項目はリストごとに一度登録すれば共通で使い、チェックの状態は期間（月・週・日）ごとに持つ。新しい期間は未チェックから始まる
  - 期間は入力で選べる。月次は年月、週次は日付（その日を含む月曜始まりの週）、日次は日付で、初期値は今月・今週・今日
  - 週次では、選んだ週の範囲（例: 11/16（月）〜11/22（日））を表示する
  - 過去のチェック状態は一定期間だけ残す（日次 90 日、週次 52 週、月次 24 か月）。それより古いものは自動で削除する
- **一時的なチェックリスト**
  - 期間に結びつかない、その場限りのリスト。項目ごとにチェックでき、チェック済みの項目をまとめて削除できる
- **4つのリストに共通**
  - 項目を追加・削除できる。各リストに完了数（例: 3/5）を表示する
  - 項目とチェックの状態は localStorage に保存し、次回表示時に復元する

あわせて、ツール登録情報に1エントリを追加し、README のツール一覧と「データの扱い」を更新する。

## Capabilities

### New Capabilities

- `tool-checklist`: 月次・週次・日次の繰り返しのチェックリスト（期間ごとのチェック、期間の選択、古い記録の削除）と一時的なチェックリスト

### Modified Capabilities

- `toolbox-shell`: 「トップページにツール一覧を表示する」と「デスクトップ幅では各ツールを縦スクロールなしで使える」のシナリオで列挙しているツールに、チェックリストを加える

## データ保存

| ツール                  | データ保存                                                                                             |
| ----------------------- | ------------------------------------------------------------------------------------------------------ |
| チェックリスト          | localStorage（4つのリストの項目、繰り返しのリストの期間ごとのチェック状態、一時的なリストのチェック状態） |
| JSON整形/検証           | なし（変更なし）                                                                                       |
| 文字数カウント          | なし（変更なし）                                                                                       |
| UUID/パスワード生成     | localStorage（パスワード生成の設定。変更なし）                                                         |
| カラー変換/コントラスト | localStorage（お気に入りの色。変更なし）                                                               |

## Out of scope

- 項目の名前の変更・並べ替え（削除して追加し直す）
- 期間ごとに項目を変えること（項目は全期間で共通）
- 前後の期間に移動するボタン、カレンダー表示、期間をまたいだ集計や履歴の一覧
- リマインダー・通知、期限、担当者、メモ
- 一時的なリストを複数作ること、リストの書き出し／読み込み
- 残す期間の変更（日次 90 日・週次 52 週・月次 24 か月で固定）

## Impact

- 追加: `lib/tools/` に期間の計算とチェックリストのデータ操作（+テスト）、`components/tools/checklist/`（+テスト）
- 変更: `components/tools/registry.ts`（+テスト）、README.md
- 依存パッケージの追加なし（日付は `Date` と `<input type="month">` / `<input type="date">`、項目の ID は `crypto.randomUUID()`）
