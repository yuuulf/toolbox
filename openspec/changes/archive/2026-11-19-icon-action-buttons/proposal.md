# Proposal

## Why

コピーボタンは「アイコンのみ」で統一したが、追加・削除・保存のように、ほかのツールでもこれから何度も使いそうな操作は、文字のボタンと × のアイコンが混ざっている。どのツールでも同じ操作が同じ見た目・同じ操作感になるよう、共通のアイコンボタンにそろえる。

## What Changes

- **共通のアイコンボタンを用意する**
  - 文字を出さないアイコンのみのボタン。何をするかはアクセシブルな名前とツールチップ（同じ文言）で示す
  - アイコンは操作ごとに決める: 追加は「+」、削除はゴミ箱、保存は保存のアイコン
- **対象のボタン**
  - チェックリストの「追加」（各リストの入力欄の横）→ 「+」のアイコンボタン。Enter キーでも追加できるのは今までどおり
  - Markdownプレビューの「保存」→ 保存のアイコンボタン
    - 結果はコピーボタンと同じく、アイコンを約2秒だけ切り替えて示す（成功は ✓、失敗は ×）
    - 結果の文言（「保存しました」「保存できませんでした」）は画面に出さず、読み上げだけで伝える
  - 削除のアイコンを × からゴミ箱に変える: カラー変換/コントラストのお気に入りの削除
  - チェックリストの各項目の削除も、いったんゴミ箱に変える。見た目を確かめたうえで、× に戻すかどうかをユーザーが決める（実装のタスクで確認する）
- 今後ツールに追加・削除・保存の操作を加えるときも、このアイコンボタンを使う（AGENTS.md の UI の約束に加える）

## Capabilities

### New Capabilities

なし

### Modified Capabilities

- `toolbox-shell`: 追加・削除・保存の操作を、アイコンのみの共通のボタンで提供する要件を加える
- `tool-markdown-preview`: 「ボタンを押したときだけ保存する」の結果の示し方を、文言の表示から、アイコンの切り替えと読み上げに変える

## データ保存

すべてのツールで変更なし（ボタンの見た目と結果の示し方の変更だけで、保存する内容は変わらない）。

## Out of scope

- そのツールに固有の操作のボタン（JSON整形/検証の「整形」「圧縮」、UUID/パスワード生成の「生成」、チェックリストの「チェック済みを削除」、Markdownプレビューの表示の切り替え）
- すでにアイコンのボタン（コピー、メニュー、お気に入りの星）の見た目の変更
- アイコンのライブラリの導入（アイコンは今のコピーボタンと同じく SVG で書く）

## Impact

- `components/icons.tsx`・`components/icon-button.tsx`・`components/save-button.tsx` の追加（+テスト）
- `components/tools/checklist/add-item-form.tsx`・`item-list.tsx`
- `components/tools/color-tool/favorite-colors.tsx`
- `components/tools/markdown-preview/markdown-preview.tsx`
- AGENTS.md の UI の約束と構成図
- 依存パッケージの追加はなし
