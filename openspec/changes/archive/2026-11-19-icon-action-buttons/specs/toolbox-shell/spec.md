# Spec Delta

## ADDED Requirements

### Requirement: 追加・削除・保存はアイコンのみのボタンで提供する
ツールの追加・削除・保存の操作は、文字を表示しないアイコンのみのボタンで提供しなければならない（SHALL）。アイコンは操作ごとにすべてのツールで同じものを使う（追加は「+」、削除はゴミ箱、保存は保存のアイコン）。ボタンは何をするかを示すアクセシブルな名前を持ち、ポインタを重ねたときに同じ名前を表示しなければならない。操作できないときは押せない状態で表示し、キーボードだけで操作できなければならない。

#### Scenario: アイコンだけを表示する
- **WHEN** チェックリスト、カラー変換/コントラストのお気に入り、Markdownプレビューを表示する
- **THEN** チェックリストの追加ボタン、お気に入りの削除ボタン、Markdownプレビューの保存ボタンには文字が表示されず、それぞれ「+」、ゴミ箱、保存のアイコンだけが表示される

#### Scenario: アクセシブルな名前とツールチップ
- **WHEN** スクリーンリーダーで追加・削除・保存のボタンに移動する、またはマウスポインタを重ねる
- **THEN** 「追加」「#336699 を削除」「保存」など、何をするかを示す名前が読み上げられる／表示される

#### Scenario: 操作できないとき
- **WHEN** チェックリストの入力欄が空である
- **THEN** 追加ボタンは押せない状態で表示される

#### Scenario: キーボードで操作する
- **WHEN** ユーザーが Tab キーで追加・削除・保存のボタンにフォーカスし、Enter または Space キーを押す
- **THEN** マウスで押したときと同じ操作が行われる
