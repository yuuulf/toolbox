# Proposal

## Why

Web 制作では、同じ色を別の形式で書き直す場面が多い。デザインツールの HEX を CSS の `rgb()` / `hsl()` にするような場面である。また、文字色と背景色の組み合わせが読みやすさの基準（WCAG のコントラスト比）を満たすかも確かめたい。毎回検索や手計算をせずに済むよう、ブラウザ内で完結するカラーツールを toolbox に加える。よく使う色はお気に入りとして保存し、すぐ呼び出せるようにする。

## What Changes

新しいツール「カラー変換/コントラスト」（`/tools/color-tool`）を追加する。

- **色形式の変換**
  - HEX（`#rgb` / `#rrggbb`）、`rgb()`、`hsl()` のどれかを入力すると、入力しながら HEX・RGB・HSL の3形式に変換して表示する
  - 変換した色をプレビューで表示する
  - 3形式それぞれを共通のコピーボタンでコピーできる
  - ブラウザのカラーピッカーで色を選んでも入力できる
  - 解釈できない入力にはエラーメッセージを表示する
- **お気に入りのカラーコード**
  - 変換欄の横の星（お気に入り）ボタンを押したときだけ、変換中の色を登録する。変換しただけでは登録しない
  - 登録済みの色ではボタンが押された状態になり、もう一度押すと登録を外せる
  - 上限は 10 件で、登録した順に一覧（色見本 + HEX）で表示する
  - 一覧の色を選ぶと変換欄に読み込み、不要な色は削除できる
  - お気に入りは localStorage に保存し、次回表示時に復元する
- **コントラスト比のチェック**
  - 文字色と背景色（変換と同じ3形式かカラーピッカーで指定）のコントラスト比を表示する
  - WCAG 2.x の AA / AAA の合否を、通常の文字と大きな文字のそれぞれについて表示する
  - 指定した2色で見本の文字を表示する

あわせて、ツール登録情報に1エントリを追加してトップの一覧・ナビゲーション・ルートに反映し、README のツール一覧にも追加する。

## Capabilities

### New Capabilities

- `tool-color-tool`: 色形式（HEX / RGB / HSL）の相互変換、プレビュー、コピー、お気に入りの保存、コントラスト比のチェック

### Modified Capabilities

- `toolbox-shell`: 「トップページにツール一覧を表示する」のシナリオで列挙しているツールに、カラー変換/コントラストを加える

## データ保存

| ツール                | データ保存                                                                               |
| --------------------- | ---------------------------------------------------------------------------------------- |
| カラー変換/コントラスト | localStorage（お気に入りの色の一覧のみ。変換中の色やコントラストの2色は保存しない） |
| JSON整形/検証         | なし（変更なし）                                                                         |
| 文字数カウント        | なし（変更なし）                                                                         |
| UUID/パスワード生成   | localStorage（パスワード生成の設定。変更なし）                                           |

## Out of scope

- 透明度（アルファ値。`#rrggbbaa`、`rgba()`、`hsla()`、`/ 0.5` などの指定）
- `red` などの色名、HWB・LAB・OKLCH など HEX / RGB / HSL 以外の形式
- 配色の生成、明暗の段階表示
- WCAG 2.x 以外のコントラストの基準（APCA など）、合格する色の自動提案
- お気に入りの並べ替え・名前付け・一括削除・書き出し／読み込み
- 変換中の色やコントラストの2色の保存（再読み込みすると既定の状態に戻る）

## Impact

- 追加: `lib/tools/` に色の変換・コントラスト・お気に入りのロジック（+テスト）、`components/tools/color-tool/`（+テスト）
- 変更: `components/tools/registry.ts`（+テスト）、README.md
- 依存パッケージの追加なし（計算は自前の純粋関数、ピッカーは `<input type="color">`）
