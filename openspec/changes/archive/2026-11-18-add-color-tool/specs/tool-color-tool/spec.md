# Spec Delta

## Purpose

色を HEX・RGB・HSL の形式で相互に変換し、よく使う色をお気に入りとして保存し、文字色と背景色のコントラスト比を WCAG 2.x の基準で確かめるツール。計算はブラウザ内で完結し、保存するのはお気に入りの一覧だけ。

## ADDED Requirements

### Requirement: 色の入力を解釈する
ツールは次の形式の色の入力を解釈しなければならない（SHALL）。前後の空白と大文字・小文字の違いは無視する。

- HEX: `#rgb` または `#rrggbb`（`#` は省略可）
- RGB: `rgb(r, g, b)` または `rgb(r g b)`。r・g・b は 0〜255 の整数
- HSL: `hsl(h, s%, l%)` または `hsl(h s% l%)`。h は 0〜360 の数値、s・l は 0〜100 の数値に `%` を付けたもの

これ以外の入力（範囲外の値、透明度の指定、色名など）は解釈できないものとして扱わなければならない。

#### Scenario: 3桁の HEX
- **WHEN** ユーザーが `#F00` を入力する
- **THEN** 赤（`#ff0000`）として解釈される

#### Scenario: スペース区切りの RGB
- **WHEN** ユーザーが `rgb(0 128 255)` を入力する
- **THEN** `#0080ff` の色として解釈される

#### Scenario: 範囲外の値
- **WHEN** ユーザーが `rgb(300, 0, 0)` を入力する
- **THEN** 解釈できない入力として扱われる

#### Scenario: 透明度の指定
- **WHEN** ユーザーが `#ff000080` または `rgba(255, 0, 0, 0.5)` を入力する
- **THEN** 解釈できない入力として扱われる

### Requirement: 色を3形式に変換して表示する
ツールは解釈できた色を、入力しながら HEX・RGB・HSL の3形式で表示しなければならない（SHALL）。HEX は小文字の `#rrggbb`、RGB は `rgb(r, g, b)`、HSL は整数に丸めた `hsl(h, s%, l%)` で表示する。あわせて、その色のプレビューを表示しなければならない。

#### Scenario: HEX から変換
- **WHEN** ユーザーが `#ff8000` を入力する
- **THEN** HEX に `#ff8000`、RGB に `rgb(255, 128, 0)`、HSL に `hsl(30, 100%, 50%)` が表示され、プレビューがその色になる

#### Scenario: HSL から変換
- **WHEN** ユーザーが `hsl(120, 100%, 25%)` を入力する
- **THEN** HEX に `#008000`、RGB に `rgb(0, 128, 0)` が表示される

### Requirement: 入力が空または解釈できないときの表示
入力欄が空（または空白のみ）のとき、ツールは3形式の表示とプレビューを空にし、色の入力を促す案内を表示しなければならない（SHALL）。案内はエラーとして強調してはならない。入力を解釈できない間は、3形式の表示とプレビューを空にしなければならない。受け付ける形式を示すエラーメッセージは、入力欄からフォーカスが外れた時点で入力を解釈できないときに表示し、入力中は表示してはならない。エラーの表示中に入力を再開したら、エラーを消し、次にフォーカスが外れたときに改めて判定しなければならない。

#### Scenario: 空入力
- **WHEN** 入力欄が空の状態でツールを表示する
- **THEN** 3形式の表示は空で、色の入力を促す案内が表示され、エラーの強調はされない

#### Scenario: 入力中はエラーを出さない
- **WHEN** ユーザーが入力欄に `rgb(` まで入力し、フォーカスは入力欄にある
- **THEN** 3形式の表示とプレビューは空になり、エラーメッセージは表示されない

#### Scenario: フォーカスが外れたらエラーを出す
- **WHEN** ユーザーが `abc-xyz` を入力し、入力欄からフォーカスを外す
- **THEN** 受け付ける形式を示すエラーメッセージが表示される

#### Scenario: 入力を再開するとエラーを消す
- **WHEN** エラーが表示されている状態で、ユーザーが入力欄に文字を入力する
- **THEN** エラーメッセージが消える

### Requirement: 変換結果をコピーする
ツールは HEX・RGB・HSL の表示をそれぞれワンクリックでクリップボードにコピーできなければならない（SHALL）。3つのコピーボタンは、アクセシブルな名前（「HEX をコピー」「RGB をコピー」「HSL をコピー」）で区別できなければならない。コピーボタンとその結果の示し方は、toolbox 共通のコピー操作の要件に従わなければならない。

#### Scenario: RGB のコピー
- **WHEN** 色を変換できている状態で、ユーザーが「RGB をコピー」を押す
- **THEN** RGB の表示文字列がクリップボードに書き込まれ、「コピーしました」が読み上げられる

#### Scenario: 変換結果がないとき
- **WHEN** 入力が空または解釈できない状態でツールを表示する
- **THEN** 3つのコピーボタンは押せない状態で表示される

### Requirement: カラーピッカーで色を入力する
ツールはブラウザのカラーピッカーで色を選べなければならない（SHALL）。ピッカーで色を選ぶと、入力欄にその色の HEX が入り、変換結果に反映されなければならない。

#### Scenario: ピッカーで選ぶ
- **WHEN** ユーザーがカラーピッカーで `#336699` を選ぶ
- **THEN** 入力欄が `#336699` になり、3形式の表示とプレビューがその色になる

### Requirement: お気に入りに登録・解除する
ツールは変換欄の横に、アクセシブルな名前「お気に入り」を持つ切り替えボタン（星）を表示しなければならない（SHALL）。お気に入りへの登録は、このボタンを押したときだけ行い、色を変換しただけで登録してはならない。登録は HEX（小文字の `#rrggbb`）で一覧の末尾に加える。変換中の色が登録済みのとき、ボタンは押された状態でなければならない。押された状態は、色だけでなく形（塗りの星と線の星）と支援技術向けの状態で示す。押された状態のボタンを押すと登録を外す。登録数の上限は 10 件とし、上限に達しているときは未登録の色を登録できず、その理由を表示しなければならない。

#### Scenario: 登録
- **WHEN** `rgb(255, 0, 0)` を変換している状態で、ユーザーがお気に入りボタンを押す
- **THEN** 一覧の末尾に `#ff0000` の色見本と HEX が加わり、ボタンが押された状態になる

#### Scenario: 登録済みの色を表示する
- **WHEN** `#ff0000` が登録されている状態で、ユーザーが `#F00` を入力する
- **THEN** お気に入りボタンが押された状態で表示される

#### Scenario: 登録を外す
- **WHEN** 登録済みの `#ff0000` を変換している状態で、ユーザーが押された状態のお気に入りボタンを押す
- **THEN** `#ff0000` が一覧から消え、ボタンが押されていない状態になる

#### Scenario: 変換しただけでは登録されない
- **WHEN** ユーザーが `#336699` を入力し、お気に入りボタンを押さずに別の色を入力する
- **THEN** `#336699` はお気に入りの一覧に加わらない

#### Scenario: 変換結果がないとき
- **WHEN** 入力が空または解釈できない状態でツールを表示する
- **THEN** お気に入りボタンは押せない状態で表示される

#### Scenario: 上限
- **WHEN** お気に入りが 10 件ある状態で、未登録の色を変換する
- **THEN** お気に入りボタンは押せない状態になり、「お気に入りは10件までです。不要な色を削除してください。」と表示される

### Requirement: お気に入りを使う・削除する
ツールはお気に入りを、色見本と HEX の一覧で表示しなければならない（SHALL）。一覧の色を選ぶと、その HEX が変換の入力欄に入らなければならない。各色は個別に削除できなければならない。お気に入りがないときは、まだ登録がないことを表示しなければならない。一覧の操作はキーボードだけで行えなければならない。

#### Scenario: お気に入りの色を使う
- **WHEN** ユーザーが一覧の `#336699` を選ぶ
- **THEN** 変換の入力欄が `#336699` になり、3形式の表示がその色になる

#### Scenario: 削除
- **WHEN** ユーザーが一覧の `#336699` の削除ボタン（アクセシブルな名前「#336699 を削除」）を押す
- **THEN** `#336699` が一覧から消える

#### Scenario: 空の一覧
- **WHEN** お気に入りが1件もない状態でツールを表示する
- **THEN** お気に入りがまだないことが表示される

### Requirement: お気に入りを localStorage に保存する
ツールはお気に入りの一覧を localStorage に保存し、次回表示時に復元しなければならない（SHALL）。保存値が不正または読み込めない場合は、空の一覧として扱わなければならない。変換中の色とコントラストの2色は保存してはならない（MUST NOT）。

#### Scenario: 再読み込みで復元
- **WHEN** ユーザーが `#ff0000` と `#336699` をお気に入りに追加してからページを再読み込みする
- **THEN** 2色が同じ順序で一覧に表示され、変換の入力欄は空で表示される

#### Scenario: 不正な保存値
- **WHEN** localStorage のお気に入りの値が JSON として壊れている状態でツールを開く
- **THEN** お気に入りは空の一覧として表示され、画面は壊れない

### Requirement: コントラスト比を表示する
ツールは文字色と背景色のコントラスト比を、WCAG 2.x の相対輝度の定義に基づいて計算し、`<比>:1` の形式で小数第2位まで表示しなければならない（SHALL）。表示の際に値を切り上げてはならない（切り捨てる）。文字色と背景色は、色の変換と同じ形式の入力かカラーピッカーで指定でき、既定値はそれぞれ `#000000` と `#ffffff` とする。指定した2色で見本の文字を表示しなければならない。

#### Scenario: 既定の2色
- **WHEN** ユーザーがツールを開く
- **THEN** 文字色 `#000000`・背景色 `#ffffff` で、コントラスト比 `21.00:1` が表示される

#### Scenario: 色を変える
- **WHEN** ユーザーが文字色を `#777777`、背景色を `#ffffff` にする
- **THEN** コントラスト比 `4.47:1` が表示され、見本の文字がその2色で表示される

#### Scenario: 解釈できない色
- **WHEN** 文字色か背景色の入力が解釈できない（空を含む）
- **THEN** コントラスト比と合否は表示されない。その入力欄からフォーカスが外れたら、どちらの入力が解釈できないかを示すエラーメッセージがその入力欄に表示される（入力中は表示されない）

### Requirement: WCAG の合否を表示する
ツールはコントラスト比について、次の4つの基準の合否を表示しなければならない（SHALL）。合否は表示用に丸める前の値で判定し、色だけでなく「合格」「不合格」の文言で示さなければならない。

- AA・通常の文字: 4.5 以上
- AA・大きな文字: 3 以上
- AAA・通常の文字: 7 以上
- AAA・大きな文字: 4.5 以上

#### Scenario: AA の境界
- **WHEN** 文字色 `#767676`、背景色 `#ffffff` を指定する（コントラスト比 4.54:1）
- **THEN** AA・通常の文字、AA・大きな文字、AAA・大きな文字が「合格」、AAA・通常の文字が「不合格」と表示される

#### Scenario: 基準を下回る
- **WHEN** 文字色 `#777777`、背景色 `#ffffff` を指定する（コントラスト比 4.47:1）
- **THEN** AA・通常の文字は「不合格」、AA・大きな文字は「合格」と表示される
