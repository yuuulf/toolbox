# Spec Delta

## ADDED Requirements

### Requirement: toolbox のファビコンを表示する
システムはすべてのページで、toolbox のアイコン（3枚のカードが重なったマーク）をファビコンとして示さなければならない（SHALL）。アイコンの背景は透明でなければならない。OS がライトモードのときは濃いグレーのカードのアイコンを、ダークモードのときは白のカードのアイコンを示さなければならない。

#### Scenario: ライトモードでページを開く
- **WHEN** OS がライトモードのブラウザで、トップページまたはいずれかのツールページを開く
- **THEN** タブに、濃いグレーのカード2枚と緑のカード1枚のアイコンが透明な背景で表示される

#### Scenario: ダークモードでページを開く
- **WHEN** OS がダークモードのブラウザで、トップページまたはいずれかのツールページを開く
- **THEN** タブに、白のカード2枚と緑のカード1枚のアイコンが透明な背景で表示される

#### Scenario: 公開版でアイコンを読み込む
- **WHEN** 公開版（`https://yuuulf.github.io/toolbox/`）のページを開く
- **THEN** ファビコンの画像は `/toolbox` の下から読み込まれ、404 にならない。Next.js の既定のロゴは表示されない

## MODIFIED Requirements

### Requirement: 共通ヘッダーとツール間ナビゲーション
システムはすべてのページに、トップページへ戻るリンクを含むヘッダーと、登録済みツールへのナビゲーションを表示しなければならない（SHALL）。現在表示中のツールはナビゲーション上で区別できなければならない。ヘッダーのアプリ名の左には toolbox のアイコンを表示し、OS のライト/ダーク設定に合わせてファビコンと同じ2種類を切り替えなければならない。アイコンは飾りとして扱い、リンクの読み上げ名はアプリ名のままでなければならない。

#### Scenario: ツールページからトップへ戻る
- **WHEN** ユーザーがツールページでヘッダーのアプリ名をクリックする
- **THEN** `/` に遷移する

#### Scenario: 現在のツールが強調される
- **WHEN** ユーザーが `/tools/id-generator` を表示している
- **THEN** ナビゲーション上の「UUID/パスワード生成」が他の項目と視覚的に区別される

#### Scenario: アプリ名の隣のアイコン
- **WHEN** ユーザーがライトモードまたはダークモードでいずれかのページを開く
- **THEN** ヘッダーの「toolbox」の左に、そのモードのファビコンと同じアイコンが表示され、アイコンをクリックしてもトップページへ遷移する。スクリーンリーダーではリンクが「toolbox」と読み上げられ、アイコンは読み上げられない
