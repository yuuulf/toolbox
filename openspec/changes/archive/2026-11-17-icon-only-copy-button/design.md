# Design

## Context

- コピーは全ツール共通の `components/copy-button.tsx`（`CopyButton`）に集約済み。利用箇所は `json-formatter.tsx`（`label` 省略＝「コピー」）と `id-generator.tsx`（「UUID をコピー」「パスワードをコピー」）の3か所
- 現状はボタン内に `label` の文字を表示し、ボタン横の `aria-live="polite"` の `<span>` に結果の文字を出している。状態は `idle | copied | failed` で、2秒（`MESSAGE_DURATION_MS`）後に `idle` へ戻る
- 既存テストは `getByRole('button', { name: ... })` と `getByText('コピーしました')` でボタンと結果を取得している
- AGENTS.md の「UI の統一」に、ボタン文言の例として「コピー」、コピーは必ず `CopyButton` を使う旨、状態を色だけで表さない旨がある

## Goals / Non-Goals

**Goals:**

- `CopyButton` の公開 API（`text` / `label`）を変えずに見た目だけをアイコン化し、利用側のコード変更を不要にする
- 既存テストのボタン・結果の取得方法（アクセシブルな名前、結果の文字）がそのまま通る構造にする

**Non-Goals:**

- アイコンを汎用コンポーネント化（`components/icons/` など）すること。現時点で使うのは `CopyButton` だけなので、同じファイル内の小さな部品に留める
- ツールチップの独自実装（ネイティブの `title` 属性で足りる）

## Decisions

### アイコンはインライン SVG を `copy-button.tsx` 内に置く

コピー・チェック・× の3種を、24px グリッドの線画（`stroke="currentColor"`）の SVG として同じファイル内の小さな関数にする。色は `currentColor` で親の文字色に従わせ、ダークモードは既存どおり Tailwind の `dark:` で切り替える。SVG には `aria-hidden="true"` と `focusable="false"` を付け、意味はボタンの名前と読み上げ用テキストで伝える。

- 代替案: アイコンライブラリ（lucide-react など）を追加 → 3種のためだけに依存を増やすのは「ブラウザ標準で足りるものに依存を追加しない」方針に反するため採らない
- 代替案: Unicode 文字（📋 / ✓ / ✕） → フォントによって見た目や幅がばらつくため採らない

### アクセシブルな名前は `aria-label`、ツールチップは `title`、どちらも `label` から

ボタンに `aria-label={label}` と `title={label}` を付ける。名前は状態によって変えない（「コピーしました」に変えても名前の変化は読み上げられないことが多く、ボタンの意味が揺れるため）。

- 代替案: ボタン内に `sr-only` の `<span>{label}</span>` を置く → 動作は同等だが、`title` と二重管理になるため `aria-label` に寄せる

### 結果の文字は `sr-only` の `aria-live` 領域に残す

ボタン横の `aria-live="polite"` の `<span>` は残し、Tailwind 標準の `sr-only` クラスで画面から隠す。文字の内容と切り替えのタイミングは現状のまま。これで既存テストの `getByText('コピーしました')` と aria-live の検証がそのまま使える。ボタンの外に置くのは、ボタンの名前と結果の読み上げを分けるため。

### アイコンの切り替えは既存の `status` から導く

`idle → コピー`、`copied → チェック`、`failed → ×` を表示する。失敗時は × の形に加えて文字色を赤系（既存の `text-red-700 dark:text-red-400`）にし、成功時は緑系（`text-green-700 dark:text-green-400`）にする。形で区別できるので色だけに頼らない。2秒後に `idle` へ戻す既存のタイマー処理はそのまま使う。

### ボタンの大きさ

アイコン `size-4`（16px）に `p-2` で約 34px 四方の正方形ボタンにし、既存の枠線・ホバー・無効時のスタイルを引き継ぐ。出力欄の見出し行に置いたとき、従来の文字ボタンより高さが大きく変わらない大きさにする。

### テストでのアイコンの判定

アイコンは意図的にアクセシビリティツリーから外すため、利用者から見える手がかりでは判別できない。AGENTS.md の方針どおり最後の手段として、SVG に `data-icon="copy" | "check" | "x"` を付け、テストはこの属性で切り替えを確認する。

### 規約の明文化

AGENTS.md の「UI の統一」を更新し、コピーはアイコンのみの `CopyButton` を使い `label` で何をコピーするかを示すこと、ボタン文言の例から「コピー」を外すことを書く。ツールの登録手順（`lib/` → `components/tools/` → `registry.ts`）は変わらない。

## Risks / Trade-offs

- [アイコンだけでは操作の意味が伝わりにくい利用者がいる] → 広く使われるクリップボード形のアイコンを使い、ホバー時のツールチップで名前を示す
- [画面上に結果の文字が出ないため、晴眼者には成功が見落とされやすい] → アイコンの形と色を2秒間切り替える。利用者が選んだ仕様として受け入れる
- [`title` のツールチップはタッチ端末やキーボードフォーカスでは表示されない] → スクリーンリーダーには `aria-label` で伝わる。見た目のツールチップ強化はスコープ外
- [`data-icon` は実装寄りのテスト手がかり] → アイコンの判定にだけ使い、ボタンや結果の取得は従来どおり role / text で行う

## Migration Plan

UI のみの変更でデータ移行はない。問題があれば `copy-button.tsx` と AGENTS.md の変更を revert すれば元に戻る。
