# Spec Delta

## MODIFIED Requirements

### Requirement: 出力をコピーする
ツールは出力結果をワンクリックでクリップボードにコピーできなければならない（SHALL）。コピー成功時はその旨を一時的に示さなければならない。コピーボタンとその結果の示し方は、toolbox 共通のコピー操作の要件（アイコンのみのボタン、アイコンの切り替えと読み上げ）に従わなければならない。

#### Scenario: コピー成功
- **WHEN** 出力がある状態でユーザーがコピーボタン（アクセシブルな名前「コピー」）を押す
- **THEN** 出力文字列がクリップボードに書き込まれ、ボタンのアイコンが一時的にチェックに変わり、「コピーしました」が読み上げられる
