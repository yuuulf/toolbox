# Proposal

## Why

コピーボタンは現在「コピー」「UUID をコピー」などの文字を表示しており、出力欄の見出し横で場所を取り、ツールごとに文言の長さも揃わない。コピーは全ツールで頻出する操作なので、一目でわかるアイコンだけのボタンにして見た目を揃え、今後追加するツールもこの見た目を標準とする。

## What Changes

- 共通の `CopyButton` を、文字を表示せずコピーアイコンだけを表示するボタンに変える
- コピー結果は、ボタンのアイコンを一時的に切り替えて示す（成功: チェック、失敗: ×）。ボタン横に表示していた「コピーしました」「コピーできませんでした」の文字は画面には表示せず、スクリーンリーダー向けの読み上げ（`aria-live`）としてだけ残す
- ボタンのアクセシブルな名前（「コピー」「UUID をコピー」「パスワードをコピー」）は従来どおり保ち、マウス利用者向けにホバー時のツールチップでも同じ名前を示す
- コピー操作はアイコンのみの `CopyButton` で提供することを、toolbox 全体の UI 規約として spec と AGENTS.md に定める（今後追加するツールにも適用）
- 既存ツール（JSON整形/検証、UUID/パスワード生成）のコピー時の表示に関する要件を、上記に合わせて更新する

## Capabilities

### New Capabilities

（なし）

### Modified Capabilities

- `toolbox-shell`: 全ツール共通の UI 規約として「コピー操作はアイコンのみのボタンで提供し、結果をアイコンの切り替えと読み上げで伝える」要件を追加する
- `tool-json-formatter`: 「出力をコピーする」のコピー成功時の表示を、文字表示からアイコンの切り替え＋読み上げに変更する
- `tool-id-generator`: 「生成結果をコピーする」のコピー時の表示を、文字表示からアイコンの切り替え＋読み上げに変更する

## データ保存

| ツール             | データ保存                                       |
| ------------------ | ------------------------------------------------ |
| JSON整形/検証      | なし（変更なし）                                 |
| UUID/パスワード生成 | localStorage（パスワード生成オプション。変更なし） |
| 文字数カウント     | 変更なし（コピーボタンを使っていない）           |

この変更でデータの保存先・保存内容は変わらない。

## Out of scope

- コピー以外のボタン（「整形」「生成」など）のアイコン化
- 文字数カウントツールなど、現在コピーボタンを持たないツールへのコピー機能の追加
- アイコンライブラリなど依存パッケージの追加（アイコンはインライン SVG で用意する）
- クリップボード書き込みの方式やコピー対象の内容の変更

## Impact

- `components/copy-button.tsx` とそのテスト
- `components/tools/json-formatter.tsx` / `components/tools/id-generator.tsx` の利用側（呼び出し方は変わらない想定。テストの確認が必要）
- `AGENTS.md` の「UI の統一」節（コピーはアイコンのみの `CopyButton` を使う旨）
- 依存パッケージの追加なし
