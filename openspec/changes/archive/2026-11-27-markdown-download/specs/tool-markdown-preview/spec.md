# Spec Delta

## ADDED Requirements

### Requirement: Markdown をファイルとしてダウンロードする
ツールは、入力欄の内容をそのまま UTF-8 の .md ファイルとしてダウンロードするボタンを持たなければならない（SHALL）。ボタンはアイコンのみで、アクセシブルな名前とツールチップは「Markdown をダウンロード」とする。ボタンは見えている欄の見出しの行に置き、どの表示でもキーボードで操作できなければならない。入力が空または空白だけのときは押せない。ファイルはブラウザ内で作り、入力内容をサーバーや外部サービスへ送信してはならない。

#### Scenario: 入力をダウンロードする
- **WHEN** ユーザーが `# メモ\n\n本文` を入力し、「Markdown をダウンロード」ボタンを押す
- **THEN** 中身が `# メモ\n\n本文` の .md ファイルがダウンロードされ、通信は発生しない

#### Scenario: どの表示でも使える
- **WHEN** 「並べて表示」「入力のみ」「プレビューのみ」のどれかを選んでいる
- **THEN** 見えている欄の見出しの行に「Markdown をダウンロード」ボタンが1つ表示される

#### Scenario: 入力が空
- **WHEN** 入力欄が空、または空白と改行だけである
- **THEN** 「Markdown をダウンロード」ボタンは押せない

#### Scenario: キーボードで操作する
- **WHEN** ユーザーが Tab でボタンへ移動し、Enter を押す
- **THEN** マウスで押したときと同じファイルがダウンロードされる

### Requirement: ファイル名を最初の見出しから付ける
ダウンロードするファイルの名前は、Markdown の最初のレベル1見出しの文字に `.md` を付けたものにしなければならない（SHALL）。コードブロックの中の行は見出しとして扱わない。ファイル名に使えない文字（`\ / : * ? " < > |` と制御文字）は取り除き、前後の空白と末尾のピリオドも取り除く。長すぎる名前は先頭から100文字で切る。見出しがない、または取り除いた結果が空になるときは `markdown.md` にする。

#### Scenario: 見出しから名前を付ける
- **WHEN** 入力の最初のレベル1見出しが `# 議事録 11/26` である
- **THEN** ファイル名は `議事録 1126.md` になる

#### Scenario: 見出しがない
- **WHEN** 入力にレベル1見出しがない（`## 小見出し` だけ、または本文だけ）
- **THEN** ファイル名は `markdown.md` になる

#### Scenario: コードブロックの中の #
- **WHEN** 入力が ` ```sh\n# コメント\n```\n\n# 本当の見出し ` である
- **THEN** ファイル名は `本当の見出し.md` になる

#### Scenario: 使える文字が残らない
- **WHEN** 最初のレベル1見出しが `# ???` である
- **THEN** ファイル名は `markdown.md` になる
