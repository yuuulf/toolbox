# Spec Delta

## MODIFIED Requirements

### Requirement: 入力が空または解釈できないときの表示
入力欄が空（または空白のみ）のとき、ツールは3形式の表示を空にし、プレビューの位置に色の入力を促す案内を表示しなければならない（SHALL）。案内のために別の行を設けてはならず、エラーとして強調してはならない。入力を解釈できない間は、3形式の表示とプレビューを空にしなければならない。受け付ける形式を示すエラーメッセージは、入力欄からフォーカスが外れた時点で入力を解釈できないときに表示し、入力中は表示してはならない。エラーの表示中に入力を再開したら、エラーを消し、次にフォーカスが外れたときに改めて判定しなければならない。

#### Scenario: 空入力
- **WHEN** 入力欄が空の状態でツールを表示する
- **THEN** 3形式の表示は空で、プレビューの枠の中に「HEX・RGB・HSL のどれかで色を入力してください。」と表示され、エラーの強調はされない

#### Scenario: 入力中はエラーを出さない
- **WHEN** ユーザーが入力欄に `rgb(` まで入力し、フォーカスは入力欄にある
- **THEN** 3形式の表示とプレビューは空になり、エラーメッセージは表示されない

#### Scenario: フォーカスが外れたらエラーを出す
- **WHEN** ユーザーが `abc-xyz` を入力し、入力欄からフォーカスを外す
- **THEN** 受け付ける形式を示すエラーメッセージが表示される

#### Scenario: 入力を再開するとエラーを消す
- **WHEN** エラーが表示されている状態で、ユーザーが入力欄に文字を入力する
- **THEN** エラーメッセージが消える

### Requirement: お気に入りに登録・解除する
ツールは変換欄の横に、アクセシブルな名前「お気に入り」を持つ切り替えボタン（星）を表示しなければならない（SHALL）。お気に入りへの登録は、このボタンを押したときだけ行い、色を変換しただけで登録してはならない。登録は HEX（小文字の `#rrggbb`）で一覧の末尾に加える。変換中の色が登録済みのとき、ボタンは押された状態でなければならない。押された状態は、色だけでなく形（塗りの星と線の星）と支援技術向けの状態で示す。押された状態のボタンを押すと登録を外す。登録数の上限は 10 件とし、上限に達しているときは未登録の色を登録できない。そのときの理由は、お気に入りの見出しの行の件数（要件「お気に入りを使う・削除する」）で示し、変換欄や見出しの行に上限を知らせる文を別に表示してはならない。ボタンには、件数を支援技術向けの説明として結びつけなければならない。

#### Scenario: 登録
- **WHEN** `rgb(255, 0, 0)` を変換している状態で、ユーザーがお気に入りボタンを押す
- **THEN** 一覧の末尾に `#ff0000` の色見本と HEX が加わり、ボタンが押された状態になる

#### Scenario: 登録済みの色を表示する
- **WHEN** `#ff0000` が登録されている状態で、ユーザーが `#F00` を入力する
- **THEN** お気に入りボタンが押された状態で表示される

#### Scenario: 登録を外す
- **WHEN** 登録済みの `#ff0000` を変換している状態で、ユーザーが押された状態のお気に入りボタンを押す
- **THEN** `#ff0000` が一覧から消え、ボタンが押されていない状態になる

#### Scenario: 変換しただけでは登録されない
- **WHEN** ユーザーが `#336699` を入力し、お気に入りボタンを押さずに別の色を入力する
- **THEN** `#336699` はお気に入りの一覧に加わらない

#### Scenario: 変換結果がないとき
- **WHEN** 入力が空または解釈できない状態でツールを表示する
- **THEN** お気に入りボタンは押せない状態で表示される

#### Scenario: 上限
- **WHEN** お気に入りが 10 件ある状態で、未登録の色を変換する
- **THEN** お気に入りボタンは押せない状態になり、ボタンの説明として件数（「10件中10件」）が支援技術に伝わる。上限を知らせる文は表示されない

### Requirement: お気に入りを使う・削除する
ツールはお気に入りを、色見本と HEX の一覧で表示しなければならない（SHALL）。お気に入りの見出しの行には、登録数と上限を `<件数>/10` の形式で常に表示しなければならない。上限に達しているかどうかは、この件数で示す。件数は支援技術にも伝わらなければならない。一覧の色を選ぶと、その HEX が変換の入力欄に入らなければならない。各色は個別に削除できなければならない。お気に入りがないときは、まだ登録がないことを表示しなければならない。一覧の操作はキーボードだけで行えなければならない。

#### Scenario: 件数の表示
- **WHEN** お気に入りが 3 件ある状態でツールを表示する
- **THEN** お気に入りの見出しの行に `3/10` が表示される

#### Scenario: 上限の表示
- **WHEN** お気に入りが 10 件ある状態でツールを表示する
- **THEN** お気に入りの見出しの行に `10/10` が表示され、上限を知らせる文は別に表示されない

#### Scenario: お気に入りの色を使う
- **WHEN** ユーザーが一覧の `#336699` を選ぶ
- **THEN** 変換の入力欄が `#336699` になり、3形式の表示がその色になる

#### Scenario: 削除
- **WHEN** ユーザーが一覧の `#336699` の削除ボタン（アクセシブルな名前「#336699 を削除」）を押す
- **THEN** `#336699` が一覧から消える

#### Scenario: 空の一覧
- **WHEN** お気に入りが1件もない状態でツールを表示する
- **THEN** 見出しの行に `0/10` が表示され、お気に入りがまだないことが表示される
