# Proposal

## Why

デスクトップでツールを使うとき、入力欄と結果が縦に積まれているため、ページをスクロールしないと結果やほかの操作に届かないツールがある。1470×800（ブラウザの表示領域）で測ると、次の3ツールがはみ出している。

| ツール                  | ページの高さ | はみ出し |
| ----------------------- | ------------ | -------- |
| JSON整形/検証           | 845px        | 45px     |
| 文字数カウント          | 800px        | なし     |
| UUID/パスワード生成     | 810px        | 10px     |
| カラー変換/コントラスト | 1102px       | 302px    |

広い画面では横幅に余裕があるので、項目を横に並べて、ツール全体を1画面に収める。完全には収まらない場合もありうるため、目標として扱う（可能な範囲で収める）。

## What Changes

- 広い画面（Tailwind の `lg`、幅 1024px 以上）では、ツールの主要な部分を2列に並べる
  - **JSON整形/検証**: 入力欄と出力欄を左右に並べる
  - **UUID/パスワード生成**: UUID とパスワードの2つのセクションを左右に並べる
  - **カラー変換/コントラスト**: 左にカラー変換とお気に入り、右にコントラスト比を並べる
  - **文字数カウント**: すでに収まっているので変えない
- 必要に応じて、ツールページの余白（上下の余白や見出しまわりの間隔）を詰める
- カラーツールで、それだけで1行を使っていた2つの案内をほかの場所に移す
  - 「HEX・RGB・HSL のどれかで色を入力してください。」は、空のプレビュー枠の中に表示する
  - お気に入りの上限の案内は表示しない。代わりに「お気に入り」の見出しの行に件数（`3/10` など）を常に表示し、`10/10` で上限とわかるようにする
- UUID/パスワード生成で、左右の列の入力欄・ボタン・結果欄の高さをそろえる（パスワードも「長さ」の横に生成ボタンを置き、文字種はその下に置く）
- 幅 1024px 未満（スマートフォン・タブレット）の表示は今と同じ縦一列のままにする
- 1470×800 で各ツールを縦スクロールなしで使えることを、toolbox 共通の表示の要件として spec に加える

## Capabilities

### New Capabilities

なし

### Modified Capabilities

- `toolbox-shell`: 「デスクトップ幅では各ツールを縦スクロールなしで使える」要件を追加する（1470×800 を目安とし、長い出力は入力欄・出力欄の中でスクロールさせる）
- `tool-color-tool`: 「入力が空または解釈できないときの表示」（案内の場所）、「お気に入りに登録・解除する」（上限の理由を件数で示す）、「お気に入りを使う・削除する」（見出しの行の件数）を変更する

## データ保存

全ツールとも変更なし（表示の配置だけを変える）。

| ツール                  | データ保存                                     |
| ----------------------- | ---------------------------------------------- |
| JSON整形/検証           | なし                                           |
| 文字数カウント          | なし                                           |
| UUID/パスワード生成     | localStorage（パスワード生成の設定）           |
| カラー変換/コントラスト | localStorage（お気に入りの色）                 |

## Out of scope

- ヘッダー・ナビゲーションのデザイン変更（1行にまとめる、固定表示にするなど）
- 1470×800 より小さいデスクトップ画面（ノートPCの 1280×720 など）での縦スクロールの解消
- 上記のカラーツールの案内と UUID/パスワード生成の配置以外の機能・文言・操作の変更
- 長い出力（UUID を 100 個生成したときなど）をページ内に収めること（入力欄・出力欄の中でスクロールする）

## Impact

- 変更: `components/tools/json-formatter.tsx`、`components/tools/id-generator.tsx`、`components/tools/color-tool/`（`color-tool.tsx`、`color-converter.tsx`、`favorite-colors.tsx`、`contrast-checker.tsx`）とそのテスト、必要に応じて `app/tools/[slug]/page.tsx`
- テスト: jsdom では配置を測れないため、既存のテストが通ることと、ヘッドレスブラウザでの高さの計測で確かめる
- 依存パッケージの追加なし
