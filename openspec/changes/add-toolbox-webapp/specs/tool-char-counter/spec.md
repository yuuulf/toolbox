# Spec Delta

## Purpose

入力テキストの文字数・行数・バイト数などを入力と同時にブラウザ内で数えるツール。データは保存しない。

## ADDED Requirements

### Requirement: 文字数を書記素単位で数える
ツールは入力テキストの文字数を、ユーザーが見た目で1文字と認識する単位（書記素クラスタ）で数えなければならない（SHALL）。改行も1文字として数える。

#### Scenario: 日本語と絵文字
- **WHEN** ユーザーが `あいう👨‍👩‍👧` を入力する
- **THEN** 文字数は 4 と表示される

### Requirement: 空白・改行を除いた文字数を数える
ツールは空白文字（半角・全角スペース、タブ、改行）を除いた文字数を表示しなければならない（SHALL）。

#### Scenario: 空白を含むテキスト
- **WHEN** ユーザーが `a b　c\n` を入力する
- **THEN** 空白除外の文字数は 3 と表示される

### Requirement: 行数を数える
ツールは行数を表示しなければならない（SHALL）。空入力の行数は 0、それ以外は改行の数 + 1 とする。

#### Scenario: 複数行
- **WHEN** ユーザーが `1行目\n2行目\n3行目` を入力する
- **THEN** 行数は 3 と表示される

#### Scenario: 空入力
- **WHEN** 入力欄が空である
- **THEN** 文字数・空白除外文字数・行数・バイト数はすべて 0 と表示される

### Requirement: UTF-8 バイト数を数える
ツールは入力テキストを UTF-8 でエンコードしたときのバイト数を表示しなければならない（SHALL）。

#### Scenario: マルチバイト文字
- **WHEN** ユーザーが `aあ` を入力する
- **THEN** バイト数は 4 と表示される

### Requirement: 入力と同時に更新する
ツールは実行ボタンなしで、入力が変わるたびにすべてのカウントを更新しなければならない（SHALL）。

#### Scenario: 入力中の更新
- **WHEN** ユーザーが1文字追加する
- **THEN** 各カウントが即座に更新される

### Requirement: データを保存しない
ツールは入力テキストを localStorage を含むいかなる場所にも保存してはならない（MUST NOT）。

#### Scenario: 再読み込み
- **WHEN** ユーザーがテキストを入力した後にページを再読み込みする
- **THEN** 入力欄は空で、各カウントは 0 と表示される
