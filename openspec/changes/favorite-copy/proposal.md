# Proposal

## Why

カラー変換/コントラストで、お気に入りの色の HEX をコピーするには、一覧の色を選んで変換欄に読み込み、変換欄の HEX のコピーボタンを押す、という2回の操作が必要になっている。お気に入りはよく使う色を取り出すためのものなので、一覧から1回の操作でコピーできるようにする。また、一覧の各色にコピーと削除のボタンが並ぶと押し間違えやすく、削除はコピーより使う頻度が低いため、一覧の削除ボタンはなくし、外すときは変換欄の星のボタンを使う。

## What Changes

- お気に入りの一覧の各色に、HEX（小文字の `#rrggbb`）をコピーするアイコンのみのコピーボタンを追加する。アクセシブルな名前とツールチップは「#336699 をコピー」の形式にする
- コピーボタンは各色の色見本のボタンの右に置く
- **BREAKING（操作の変更）** 一覧の各色の削除ボタンをなくす。お気に入りから外すときは、一覧の色を選んで変換欄に読み込み、押された状態の星のボタンを押して外す（星のボタンで外す動きは既存のまま）
- コピーの結果は、ほかのコピーボタンと同じく、アイコンの切り替えと読み上げで伝える（共通の `CopyButton` を使う）
- 一覧の中で目立ちすぎないよう、`CopyButton` に、`IconButton` の subtle と同じ枠なしの見た目を選べるようにする
- 色見本を押すと変換欄に読み込む動き、星のボタンでの登録・解除は変えない

### Out of scope

- RGB・HSL の形式でのコピー（お気に入りは HEX で保存しているため、HEX だけにする）
- 色見本を押したときにコピーも行うこと（読み込みたいだけのときにクリップボードを上書きしてしまうため）
- お気に入りの並べ替え、上限の変更
- ほかのツールのコピーボタンの見た目（既定の枠ありのまま）

### データ保存

- カラー変換/コントラスト: localStorage（お気に入りの色のみ。保存する内容は変えない）

## Capabilities

### New Capabilities

なし

### Modified Capabilities

- `tool-color-tool`: 要件「お気に入りを使う・削除する」に、一覧の各色の HEX を1回の操作でコピーできることを加え、一覧での個別の削除をやめて、外すときは星のボタンを使うことにする
