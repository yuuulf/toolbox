# Spec Delta

## MODIFIED Requirements

### Requirement: お気に入りを使う・削除する
ツールはお気に入りを、色見本と HEX の一覧で表示しなければならない（SHALL）。お気に入りの見出しの行には、登録数と上限を `<件数>/10` の形式で常に表示しなければならない。上限に達しているかどうかは、この件数で示す。件数は支援技術にも伝わらなければならない。一覧の色を選ぶと、その HEX が変換の入力欄に入らなければならない。各色の HEX は、一覧から1回の操作でクリップボードにコピーできなければならない。コピーボタンは各色ごとに置き、アクセシブルな名前（「#336699 をコピー」の形式）で色を区別できなければならない。コピーボタンとその結果の示し方は、toolbox 共通のコピー操作の要件（アイコンのみのボタン、アイコンの切り替えと読み上げ）に従わなければならない。各色は個別に削除できなければならない。お気に入りがないときは、まだ登録がないことを表示しなければならない。一覧の操作はキーボードだけで行えなければならない。

#### Scenario: 件数の表示
- **WHEN** お気に入りが 3 件ある状態でツールを表示する
- **THEN** お気に入りの見出しの行に `3/10` が表示される

#### Scenario: 上限の表示
- **WHEN** お気に入りが 10 件ある状態でツールを表示する
- **THEN** お気に入りの見出しの行に `10/10` が表示され、上限を知らせる文は別に表示されない

#### Scenario: お気に入りの色を使う
- **WHEN** ユーザーが一覧の `#336699` を選ぶ
- **THEN** 変換の入力欄が `#336699` になり、3形式の表示がその色になる

#### Scenario: お気に入りの色をコピーする
- **WHEN** ユーザーが一覧の `#336699` のコピーボタン（アクセシブルな名前「#336699 をコピー」）を押す
- **THEN** `#336699` がクリップボードに書き込まれ、ボタンのアイコンが一時的にチェックに変わり、「コピーしました」が読み上げられる。変換の入力欄は変わらない

#### Scenario: キーボードでコピーする
- **WHEN** ユーザーが Tab キーで一覧の `#336699` のコピーボタンにフォーカスし、Enter キーを押す
- **THEN** `#336699` がクリップボードに書き込まれる

#### Scenario: 削除
- **WHEN** ユーザーが一覧の `#336699` の削除ボタン（アクセシブルな名前「#336699 を削除」）を押す
- **THEN** `#336699` が一覧から消える

#### Scenario: 空の一覧
- **WHEN** お気に入りが1件もない状態でツールを表示する
- **THEN** 見出しの行に `0/10` が表示され、お気に入りがまだないことが表示される
