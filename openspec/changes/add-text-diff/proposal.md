# Proposal

## Why

文章や設定ファイル・コードの2つの版のどこが違うかを確かめたいときに、外部の差分サイトへ貼り付けずにブラウザ内で比べたい。入力内容を外へ送らない toolbox の方針に合う、テキスト差分比較ツールを加える。

## What Changes

新しいツール「テキスト差分比較」（`/tools/text-diff`）を追加する。

- 「変更前」「変更後」の2つの入力欄にテキストを入れると、入力と同時に比較結果を表示する（ボタンは押さない）
- 比較は行単位で行い、追加・削除された行を示す。変更された行の組（削除された行と、その位置に追加された行）は、行の中で変わった文字も強調する
- 結果は左右に並べて表示する（左に変更前、右に変更後、同じ行は横にそろえる）。両側に行番号を付ける。画面幅が狭いときは1列にまとめて表示する
- 追加・削除は色だけでなく、行頭の記号（`+` / `-`）と読み上げ用の文言でも示す
- 両方空のときは入力を促す案内を、内容が同じときは「差分はありません。」を表示する
- 比較オプション（空白・大文字小文字の無視など）や件数の集計は付けない
- ツール登録情報に1エントリを追加し、README のツール一覧を更新する

## Capabilities

### New Capabilities

- `tool-text-diff`: 2つのテキストの行単位の差分と、変更された行の中の文字単位の差分を、左右に並べて表示する

### Modified Capabilities

- `toolbox-shell`: 「トップページにツール一覧を表示する」と「デスクトップ幅では各ツールを縦スクロールなしで使える」のシナリオで列挙しているツールに、テキスト差分比較を加える

## データ保存

| ツール                  | データ保存                                            |
| ----------------------- | ----------------------------------------------------- |
| テキスト差分比較        | なし（入力したテキストは保存せず、再読み込みで消える） |
| JSON整形/検証           | なし（変更なし）                                      |
| 文字数カウント          | なし（変更なし）                                      |
| UUID/パスワード生成     | localStorage（変更なし）                              |
| カラー変換/コントラスト | localStorage（変更なし）                              |
| チェックリスト          | localStorage（変更なし）                              |

## Out of scope

- 比較オプション（空白の無視、大文字小文字の無視、改行コードの無視）
- 追加・削除の件数の集計
- 1列（unified）表示と左右表示の切り替え（狭い画面での1列表示は自動で行う）
- ファイルの読み込み、差分の書き出し（patch 形式など）、結果のコピー
- 単語単位の差分、3つ以上のテキストの比較

## Impact

- `lib/tools/text-diff.ts`（+テスト）の追加
- `components/tools/text-diff/`（+テスト）の追加
- `components/tools/registry.ts` に1エントリ、`registry.test.ts` の件数
- README.md のツール一覧
- 依存パッケージの追加はなし（差分のアルゴリズムは自前で実装する）
