# Proposal

## Why

いまの toolbox で色が付いているのは、Markdownプレビューのリンク（Tailwind の青）と、ブラウザ既定の青で描かれるチェックボックスとフォーカスリングだけで、アプリとしての色が決まっていない。アクセントの色を #009688（ティール）に決め、青を使っている部分をこの色にそろえる。

## What Changes

- アクセント色を #009688 を基準とするティールの3段階（明るい・基準・濃い）として定義する
- 現在青で表示している部分をアクセント色に変える
  - Markdownプレビューのリンクの文字色（今は `blue-700` / ダーク時 `blue-400`）
  - 操作できるチェックボックス（チェックリスト、UUID/パスワード生成の文字種）の、チェック時の塗り（今はブラウザ既定の青）
  - 入力欄・ボタン・リンクなどのフォーカスリングの色（今はブラウザ既定の青）。形はブラウザ既定のまま変えない
- 文字のコントラストは WCAG AA（4.5:1）を満たすようにする。#009688 は白背景の文字として 3.67:1 で足りないため、ライトでは濃いティール（#00796b、白背景で 5.32:1）を文字に使う。ダークでは明るいティール（#4db6ac、`zinc-950` 背景で 8.15:1）を使う。チェックボックスとフォーカスリングは文字ではない部品なので、ライトでは #009688 のまま（白背景で 3.67:1、非テキストの基準 3:1 を満たす）にする
- AGENTS.md の「色は Tailwind の既定スケールを使う」に、アクセント色の定義を例外として追記する

### Out of scope

- 塗りつぶしの主ボタン（「整形」「生成」など）、`IconButton` の primary、ナビの現在地、Markdown の表示切替の選択中は、今の zinc の白黒のまま変えない
- 操作できない（disabled の）チェックボックス。Markdownプレビューのタスクリストがこれにあたり、今も青ではなくブラウザ既定の灰色で表示されるため、そのままにする
- 成功・失敗を表す緑・赤、差分表示の色、カラー変換の警告の琥珀色
- Mermaid の図の配色
- ファビコン・アイコン画像

### データ保存

- 保存なし（すべてのツールで、保存する内容・保存先は変わらない）

## Capabilities

### New Capabilities

なし

### Modified Capabilities

- `toolbox-shell`: 全ツール共通のアクセント色（リンクとチェックボックスの色、コントラストの条件）の要件を追加する

## Impact

- `app/globals.css`: Tailwind のテーマにアクセント色を追加する
- `app/globals.css`: `:focus-visible` のフォーカスリングの色を指定する
- `app/layout.tsx`: `<body>` にチェックボックスなどのフォーム部品の色（accent-color）を指定する
- `components/tools/markdown-preview/markdown-view.tsx`: リンクの文字色（とテスト）
- AGENTS.md: 色の規約にアクセント色（フォーカスリングを含む）を追記する
- 依存パッケージの追加なし。README の更新は不要（ツール・データの扱い・手順は変わらない）
